**Privacy Policy URL** — ⚠️ drafted in `LAUNCH/privacy-policy.html`. Publish it as `index.html` (and `support.html` beside it) in a public `riffology-privacy` repo with GitHub Pages, following `Cross Word Puzzle/LAUNCH/github-pages-setup.md`:

`app/settings.tsx` already links to this URL and to `support.html`, and shows an "Ad privacy choices" row to EEA/UK/Swiss players (Google requires it).

Riffology has **no analytics, no crash reporter, no backend and no account** — AdMob is the only SDK that collects anything. Declare these (all **Not linked** to identity):

| Data Type | Collected | Linked | Tracking | Purpose | SDK |
|---|---|---|---|---|---|
| **Location → Coarse Location** (IP-derived) | Yes | No | No | Third-Party Advertising | AdMob |
| **Identifiers → Device ID** | Yes | No | **Yes** (only if ATT granted) | Third-Party Advertising, Analytics | AdMob |
| **Usage Data → Advertising Data** | Yes | No | **Yes** (only if ATT granted) | Third-Party Advertising, Analytics | AdMob |
| **Usage Data → Product Interaction** | Yes | No | No | Third-Party Advertising, Analytics | AdMob (ad taps/views) |
| **Diagnostics → Crash Data** | Yes | No | No | App Functionality | AdMob SDK |
| **Diagnostics → Performance Data** | Yes | No | No | App Functionality | AdMob SDK |

Everything else → **Not Collected**, including:
- **Purchases**: Apple processes the payment; the app only reads its own entitlement from StoreKit, on device.
- **Audio**: the app plays audio but never records, and declares no microphone permission.
- **User content**: saved riffs and practice history stay in on-device storage.

Reference: [Google's AdMob iOS data-disclosure guidance](https://developers.google.com/admob/ios/privacy/data-disclosure). The policy's AdMob paragraph should name IP address (general location), the advertising identifier (with ATT consent), and ad interaction data.

## 7 — Build

Select the production build once processing finishes (`eas build -p ios --profile production` → `eas submit -p ios`; ~15–30 min after upload).

- **Export compliance:** already answered in the binary (`ITSAppUsesNonExemptEncryption: false`) — no questions.
- **Copyright:** `© 2026 Andrew Murphy`

> ⚠️ **Before the production build:** `app.json` sets `NSAllowsArbitraryLoads: true`. The app makes no network requests of its own, and the AdMob SDK hasn't needed this for years; it looks like a dev-server leftover. App Review can ask you to justify it. Recommend removing it and keeping only `NSAllowsLocalNetworking` (dev client). Check that the dev client still connects before the production build.
